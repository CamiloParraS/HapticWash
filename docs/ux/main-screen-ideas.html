Start screen: three directions

The old line “4 of 5 steps covered” counts but doesn’t say anything you can act on. Every direction below tries to say which Step the last Wash missed, not just how many. Switch the state to see how each holds up.

A · Evolve

Same stack, readable

Keeps today’s order: ring, result, Start, shortcuts. The result line names the gap.

Last wash as a quiet strip on top. A big Start pill dead centre. Shortcuts shrink to the bottom.

My pick: C

The ring already is the app’s signature: it fills during a Wash, it is the Summary hero, it is on the Tile. On Start it currently shrinks to a 60 dp badge and has to be explained with text. Promoted to the bezel it explains itself, costs no centre space, and leaves Start as the only filled control on screen.

If C feels like too big a change, A is the safe fix: swap “4 of 5 steps covered” for the missed Step’s name and drop the time to a quieter second line. B is the right call only if you decide the last-Wash result is not part of Start’s job.
